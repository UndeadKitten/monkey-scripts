# Open Bing Related Videos In New Tab
[Install](https://github.com/UndeadKitten/monkey-scripts/raw/refs/heads/main/Open%20Bing%20Related%20Videos%20In%20New%20Tab.user.js)

Restores old Bing functionality when clicking on related videos. Middle-click or Ctrl+click to open them in a new tab. Left-click works normally. Right-click shows proper link context menu.

Also makes the currently embedded video's hyperlinks (title, host website, and uploader) match the functionality of clicking on a related video's host website.

Has a config so you can change the the functionality of mouse clicks. You can also force the Vidadt (old) layout on or off, as well as automatically change the search query to the title of the related video you clicked on. Also has a setting to refresh the page when left clicking a related video.
